# 千牛模板上品草稿脚本

选择含 `product.txt` 和 `images` 的模板文件夹，脚本会在专用 Edge 窗口打开千牛的「手机保护套/壳」发布页，以可见界面操作并保存草稿。脚本不会点击「提交宝贝信息」。

## 运行

1. 在 Windows 安装 Node.js 20 或更新版本、Microsoft Edge。
2. 在本项目目录运行 `npm install`。
3. 双击 `draft.cmd`，选择模板文件夹。第一次运行会打开专用 Edge；请在该窗口完成千牛登录，脚本会等待登录并自动继续（最长 5 分钟）。命令窗口会显示当前进度。
4. 查看命令行进度和 `artifacts/latest-draft.json`。失败时会另存 `artifacts/latest-error.png`，浏览器页面保留，可直接检查。

也可在 PowerShell 指定模板路径：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bin\run.ps1 -Action draft -Folder 'C:\Users\24114\Desktop\testproduct'
```

先校验模板：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bin\run.ps1 -Action check-template -Folder 'C:\Users\24114\Desktop\testproduct'
```

## 模板和规则

- `product.txt` 使用当前测试模板的 `## 来源链接`、`## 商品 ID`、`## 标题`、`## 分类`、`## 商品参数`、`## 规格` 结构。
- `images` 中主图命名为 `主图-01.jpg` 等，详情图为 `详情-01.jpg` 等，颜色图为 `SKU-01-颜色.jpg` 等。按编号顺序处理，主图最多取前 5 张。
- 上传图片前会在千牛「图片空间」的「全部图片」下创建以宝贝标题前三个字符命名的文件夹；同名文件夹会复用。主图、详情图和 SKU 图片都上传至这个文件夹，视频仍走千牛视频空间。
- 品牌固定选择千牛中的 `RHODE`；SKU 售价按进价加 10 元；每条库存为 1000；运费模板保持千牛页面当前设置。
- 颜色与型号都存在多个值时，使用千牛「分层展示·选择标准属性构建规格」，建成颜色分类 × 适用手机型号两层，SKU 图片绑定颜色层。只有一个变化属性时使用单层规格。
- 模板里的组合型号（例如「苹果13/14/15（手机壳+唇釉+纸盒包装）」）会拆成千牛标准单机型。拆分后的 SKU 沿用原组合的进价和颜色图片。运行前的摘要会显示拆分后的目标 SKU 数；若拆分产生重复或非完整组合，脚本会停止。
- 非标准颜色会选择相近的千牛标准主色，并把原颜色名写入备注。例如「亮粉色」显示为「粉红色(亮粉色)」。颜色图使用千牛的方图裁剪功能。
- 若 SKU 进价不同，脚本会按颜色和型号逐条填写售价并校验；进价相同时使用千牛批量填写。
- 视频文件命名为 `视频-01.mp4` 等，脚本取第一段上传；详情图、主图和 SKU 搜索主图也会自动处理。

每次运行新建一个商品发布标签页。请检查草稿内的类目、品牌、图片以及平台提示，再自行决定是否提交上架。

当前测试模板有 247 条原始 SKU，拆分为 13 种颜色 × 28 个标准型号，共 364 条。此前测试保存的 247 条单层草稿仍在店铺草稿中，可按需手动删除。
